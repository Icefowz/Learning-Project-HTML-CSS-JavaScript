# Learning-Project-HTML-CSS-JavaScript

A small learning project demonstrating a simple website built with HTML, CSS and JavaScript.

## Description

This repository contains a static website used for learning and experimenting with front-end technologies: HTML for structure, CSS for styling (including media queries), and JavaScript for interactivity.

## Technologies

- HTML
- CSS (files in `css/`, including responsive rules)
- JavaScript (plain ES6 in `JS/`)

## Project Structure

- [index.html](index.html) — Main entry page
- [content.md](content.md) — Project content / notes
- css/ — Stylesheets (`style.css`, `quaries.css`)
- JS/ — JavaScript files (`script.js`)
- img/ — Image assets and subfolders for categories

## How to run

1. Open [index.html](index.html) in a browser (double-click or serve with a simple HTTP server).

Optional: serve locally with Python 3:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```
